Belangrijke ontwerpprincipes

Gescheiden verantwoordelijkheden

Elke agent heeft een eigen, afgebakende taak en eigen tools. Geen enkele agent kan buiten zijn eigen domein handelen — de Matching-agent kan bijvoorbeeld nooit zelf een uitbetaling doen.

Drie-lagen escalatie

Tier 1: agent handelt zelfstandig af. Tier 2: agent voert uit, tenzij Sebas binnen X uur ingrijpt. Tier 3: agent wacht altijd op expliciete keuze van Sebas voordat er iets gebeurt.

Geld gaat nooit automatisch de deur uit

De Financieel-agent bereidt uitbetalingen voor en berekent bedragen, maar keurt nooit zelf goed. Elke uitbetaling — bonussen, facturen — vereist een klik van Sebas in het directiedashboard.

Alles wordt gelogd

Elke actie van elke agent komt in het activiteitenlog terecht, doorzoekbaar en per afdeling gefilterd — zodat Sebas op elk moment kan navragen wat er is gebeurd en waarom.
